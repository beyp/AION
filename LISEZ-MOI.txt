INTEGRATION
-----------
1. Copier tous les fichiers dans votre repo (branch develop)
2. Installer les dependances :
     pip install -r requirements.txt
3. Lancer les tests :
     pytest
4. Demarrer AION :
     python main.py
5. Dans la console AION, taper :
     api start          -> lance http://127.0.0.1:8000
     scheduler          -> statut du planificateur
     schedule ping every 60s  -> planifie le service ping

NOUVELLES COMMANDES CONSOLE
----------------------------
scheduler                         Statut du planificateur
schedule <service> every <N>s     Planifie un service (ex: 60s)
unschedule <job_id>               Supprime un job
pause job <job_id>                Met un job en pause
resume job <job_id>               Reprend un job
api start                         Lance le serveur REST sur :8000

API REST ENDPOINTS
------------------
GET  /                            Status AION
GET  /status                      Status complet
GET  /services                    Liste des services
GET  /services/{name}             Detail d un service
POST /run/{name}                  Execute un service
POST /services/reload             Recharge les services
GET  /memory                      Liste la memoire
GET  /memory/stats                Stats memoire
GET  /memory/search?q=...         Recherche memoire
GET  /memory/{key}                Lire une cle
PUT  /memory/{key}                Ecrire une cle
DELETE /memory/{key}              Supprimer une cle
GET  /scheduler                   Liste les jobs
POST /scheduler/jobs              Ajouter un job
DELETE /scheduler/jobs/{id}       Supprimer un job
POST /scheduler/jobs/{id}/pause   Mettre en pause
POST /scheduler/jobs/{id}/resume  Reprendre

Docs Swagger : http://127.0.0.1:8000/docs
