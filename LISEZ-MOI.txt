AION Dashboard v2 - Sidebar + Console + Drag & Drop
=====================================================

FICHIERS DANS CE ZIP
--------------------
A REMPLACER :
  aion/dashboard/server.py

NOUVEAUX :
  aion/dashboard/templates/dashboard.html       Page principale
  aion/dashboard/templates/sections/status.html
  aion/dashboard/templates/sections/services.html
  aion/dashboard/templates/sections/scheduler.html
  aion/dashboard/templates/sections/memory.html
  aion/dashboard/templates/sections/network.html
  aion/dashboard/templates/sections/system.html
  aion/dashboard/templates/sections/docker.html
  aion/dashboard/templates/sections/quickmind.html
  aion/dashboard/templates/sections/console.html

A SUPPRIMER (anciens fragments) :
  aion/dashboard/templates/fragments/  (dossier entier)

LANCEMENT
---------
  python main.py
  AION> api start
  -> http://127.0.0.1:8000/dashboard

OU directement :
  python -m aion.api.run_dashboard

FONCTIONNALITES
---------------
- Sidebar avec drag & drop (SortableJS)
- Ordre persistant dans localStorage
- Thème dark/light toggle (persistant)
- Console interactive :
    - Historique (fleches haut/bas)
    - Autocompletion Tab des services
    - Boutons commandes rapides
- Section QuickMind : lister + creer taches
- Section Scheduler : pause/resume/delete jobs
- Refresh automatique via htmx
- Toutes les sections chargees a la demande
