NOMENCLATURE
------------
Format : <domaine>_<action>
Domaines par defaut :
  net    : reseau (ping, IP, status...)
  sys    : systeme (CPU, disque, uptime...)
  docker : Docker
  ai     : IA (ollama...)
  fs     : fichiers
  svc    : services applicatifs
  demo   : demonstration

NOUVELLES COMMANDES
-------------------
domains                       Lister les domaines
domain add <nom> <desc>       Ajouter un domaine
create service <description>  Creer un service via IA

CREATION DE SERVICE PAR IA
--------------------------
AION> create service surveille la temperature CPU
AION> ai
🤖 AION AI> cree un service qui liste les processus qui consomment le plus de RAM
