INTEGRATION
-----------
1. Copier tous les fichiers dans votre repo (branch develop)
2. Creer le dossier assets/ a la racine (optionnel, pour aion.ico)
3. Installer les dependances :
     pip install -r requirements.txt
4. Lancer AION :
     python main.py
5. Taper dans la console :
     api start   -> lance http://127.0.0.1:8000/dashboard

NOUVELLES COMMANDES CONSOLE
----------------------------
run cpu_monitor          Voir CPU / RAM
run disk_monitor         Voir les disques
run uptime               Uptime de la machine
run docker_status        Conteneurs Docker actifs
notify on                Activer les toasts Windows
notify off               Desactiver les toasts Windows
notify status            Voir l etat des notifications

SYSTRAY
-------
- Icone AION dans la barre de statut Windows
- Menu clic-droit :
    Toggle Notifications ON/OFF
    Ouvrir le Dashboard
    Lancer l API REST
    Ouvrir les logs
    Quitter AION

DASHBOARD
---------
URL : http://127.0.0.1:8000/dashboard
- Statut general (refresh auto 10s)
- Liste des services avec bouton Run (htmx)
- Scheduler avec etat running/paused
- Memoire persistante
